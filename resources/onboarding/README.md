# Onboarding

Everything a new member needs to get started on **this team**. Do not replicate general AguaClara onboarding materials (e.g. Git basics, New Member Class slides, Python tutorial).

## Suggested Contents

- **Team overview:** what the team is trying to achieve and where the project stands
- **Reading list:** the 3-5 documents to read first (link to files in this repo)
- **Equipment and lab safety:** what equipment/chemicals you'll use and corresponding SOPs/required safety training
- **Who to contact:** current advisors and subteam lead
