## Contributing

- Write descriptive commit messages. For a simple file upload, use one line describing the file, e.g. `Add Spring 2026 final report`.
- For larger changes, use the following template:

  ```
  A brief one-line description of the changes made

  - A bulleted list of details about the changes (leave the blank line above!)
  - More information about the changes
  ```

- Don't commit system files or checkpoints (`.DS_Store`, `.ipynb_checkpoints`). The template `.gitignore` covers these.
