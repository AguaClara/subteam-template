# YY-N-SS

Keep this folder as a template.

## Setup Checklist

1. Copy this folder.
2. Rename the folder to the current semester, e.g. `26-1-SP` (Spring = 1-SP, Summer = 2-SU, Fall = 3-FA).
3. Delete `README.md` files from the new semester folder, `presentations/`, and `reports/`.

## Folder Structure

| Folder | What goes in it |
| --- | --- |
| `reports/` | Final report/manual, midsemester report (PDF + editable) |
| `presentations/` | Symposium presentation, final poster (PDF + editable) |

## Deliverable Guidelines

- Deliverables (i.e. `reports/` and `presentations/`) should have both a PDF and an editable version (docx, pptx, ipynb, tex, etc.) with the same file name.
- Files should be named `YYYYSS-Team-Document.ext`, for example `2025SP-UASB-Final-Report.pdf`.
- Do **NOT** upload recordings of presentations. Upload recordings to YouTube, then link to them from the main [`README.md`](../README.md).
