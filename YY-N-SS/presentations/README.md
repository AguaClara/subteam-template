Naming: `YYYYSS-Team-Document.ext`, e.g. `2026SP-UASB-Final-Presentation.pdf` and `2026SP-UASB-Final-Presentation.pptx`.

Recordings: upload to YouTube and link them from the main README. Don't commit video files.
